# Laika-RWD
Makes the Laika RWD.

# What can be expected after installing the Mod?
The Laika will undergo a wheel-drive conversion, causing the front end to lift under acceleration.


# How to install
• Make sure you have JaLoader 1.1.1+ installed

Manual method: Place it in your mods folder (default is Documents/Jalopy/Mods)

# Automatic method:
• This requires that the Enable JaDownloader setting in Modloader Options/Preferences in-game is set to Yes

• Open this link in a browser:

• jaloader://install/jalopy-mods/LaikaAddons
